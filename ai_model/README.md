## 1. What is Generative AI?
Generative Artificial Intelligence refers to a class of machine learning models that generate **new content** (images, audio, code, or text) that closely mimics the distribution of real-world training data.

Unlike **Discriminative AI** (which computes $P(y|x)$ to categorize an image into classes like "cat" vs. "dog"), **Generative AI** models learn the underlying probability distribution $P(x)$ or conditional distribution $P(x|c)$ (where $c$ is a text prompt). This enables the model to sample novel synthetic outputs from high-dimensional latent space.

## 2. Generative Approach: Latent Diffusion vs. GANs

### Why We Selected Latent Diffusion Models (LDMs)
Two prominent generative paradigms for visual content creation are **Generative Adversarial Networks (GANs)** and **Diffusion Models**:

| Feature | Generative Adversarial Networks (GANs) | Latent Diffusion Models (LDMs) |
| :--- | :--- | :--- |
| **Architecture** | Generator vs. Discriminator minimax game | Forward Markov noise chain & Reverse U-Net denoiser |
| **Training Stability** | Prone to mode collapse and training instability | Highly stable likelihood-based training |
| **Text-Conditioning** | Hard to align with complex natural language prompts | Superior semantic alignment via cross-attention (CLIP) |
| **Diversity & Quality**| Good at fixed domains (e.g. human faces) | Unmatched versatility for stylized & fantasy landscapes |

In this project, we implement **Latent Diffusion** via `stabilityai/sd-turbo` (an adversarial diffusion distillation model capable of high-fidelity synthesis in 1 to 4 steps) and standard Stable Diffusion (`runwayml/stable-diffusion-v1-5`).

## 3. The Role of PyTorch & TensorFlow in the Implementation

### What PyTorch Does:
1. **Tensor Computation & Linear Algebra:** PyTorch provides n-dimensional tensor arrays with hardware acceleration on CUDA GPUs and MPS (Apple Silicon).
2. **Model Weight Loading:** Loads pre-trained multi-gigabyte neural network checkpoints (Text Encoder, Latent Variational Autoencoder (VAE), and Denoising U-Net).
3. **Inference Pipeline:** Executes matrix multiplications and cross-attention operations across the neural layers to convert random latent tensors into structured visual features.
4. **Memory Optimization:** Uses 16-bit half-precision floating point (`torch.float16`) to fit inside standard laptop GPUs (4GB–8GB VRAM).

*(Note: TensorFlow equivalents like Keras-CV Stable Diffusion follow the exact same mathematical foundation, but PyTorch + Hugging Face `diffusers` was selected for its widespread support and minimal boilerplate).*

## 4. How the Model Generates Artwork from a Text Prompt

The generation process in `generate_art.py` follows four sequential stages:

```
[User Text Prompt]
       │
       ▼
1. CLIP Text Tokenizer & Transformer Encoder 
       │ (Embeds prompt into 768-dim semantic vectors)
       ▼
2. Random Gaussian Noise Initialization in Latent Space (z ~ N(0, I))
       │
       ▼
3. Reverse Diffusion Denoising Loop (U-Net + Cross Attention)
       │ (U-Net iteratively predicts and subtracts noise conditioned on text embeddings)
       ▼
4. Variational Autoencoder (VAE) Decoder
       │ (Expands 64x64 latent tensor into 512x512 / 1280x720 RGB pixel image)
       ▼
[Saved Artwork: assets/generated/*.jpg]
```

## 5. How Generated Artwork is Integrated into the Game

1. **Storage Pipeline:** Images generated by `generate_art.py` are saved directly into `assets/generated/` and synchronized to `assets/images/`.
2. **Three.js Texture Mapping:** In `game.js`, Three.js's `THREE.TextureLoader` loads the generated image files:
   ```javascript
   const texture = new THREE.TextureLoader().load('assets/images/magical_forest_path.jpg');
   texture.wrapS = THREE.RepeatWrapping;
   texture.repeat.set(3, 1);
   const panoMat = new THREE.MeshBasicMaterial({ map: texture, side: THREE.BackSide });
   ```
3. **Dynamic Panoramic Horizon:** The texture is mapped onto an inverted 3D cylindrical horizon mesh that tracks the player's camera, creating a breathtaking cartoon backdrop with depth and parallax.
4. **Theme Switcher:** When the player reaches the sunset section (or toggles the theme picker on the start screen), the Three.js material dynamically crossfades to the corresponding AI-generated skybox artwork.

## 6. How to Run the Python Generative AI Module

### Requirements:
- Python 3.9+ installed
- Optional: NVIDIA GPU with CUDA for fastest inference (CPU is also supported)

### Step 1: Install Dependencies
Open your terminal in the `boy` directory:
```bash
pip install -r ai_model/requirements.txt
```

### Step 2: Generate Game Backgrounds
Generate all three chapters with one command:
```bash
python ai_model/generate_art.py --theme all
```

Or generate a specific scene:
```bash
python ai_model/generate_art.py --theme sunset
```

Generate with a custom prompt:
```bash
python ai_model/generate_art.py --prompt "A dreamy neon twilight runner track with floating stars and roses" --output_name custom_sunset.jpg
```

### Step 3: Test Without GPU / Model Downloads
If you are on a low-spec machine without a dedicated GPU, run:
```bash
python ai_model/generate_art.py --cpu
```
The script will cleanly execute, downloading lightweight weights or invoking the mathematical gradient synthesizer so you can test the entire pipeline without crashing.
